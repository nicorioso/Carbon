# ADR-004 · Sistema centralizado de tokens visuales

**Estado** Aceptada para implementación futura.

Usar `theme.json` como fuente de roles visuales y Python estándar para generar formatos nativos. Validar determinismo, parser y paridad visual en staging. Las divergencias actuales requieren registro y una decisión explícita antes de cambiar valores. [Estrategia de generación](../ARCHITECTURE.md)
