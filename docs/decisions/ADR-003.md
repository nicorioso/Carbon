# ADR-003 · Respaldo y restauración

**Estado** Aceptada.

Cada tanda necesita un respaldo previo fuera de Git y un manifiesto con presencia, tipo, modo, hash o destino de enlace. Verificar integridad y ensayar en staging antes de aplicar. Restaurar por archivo con temporales en el directorio de destino y mover a cuarentena candidatos originalmente ausentes. La restauración del greeter exige un flujo de mantenimiento separado.
