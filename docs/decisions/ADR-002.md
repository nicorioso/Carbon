# ADR-002 · Gestión de dotfiles y estrategia Git

**Estado** Aceptada.

Versionar copias explícitamente seleccionadas en un repositorio local, con correspondencia directa bajo `dotfiles/`. Revisar cada incorporación y sus referencias antes del commit. Los archivos privados y el estado de aplicaciones quedan en su ámbito local. El árbol activo conserva sus propios archivos y se desplegará solo tras autorización. [Correspondencia](../INSTALL.md)
